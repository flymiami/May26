# Mini FLY Duck — Social Media Operating System

The complete brand + content playbook for launching and growing the **Mini FLY Duck**
character account: a fun, feel-good 3D mascot who dances, drops quotes, gives advice,
cracks jokes, and spreads good energy — one short reel a day.

Reference north star: [@buckethat_tim](https://www.instagram.com/buckethat_tim) —
the blueprint for a recurring 3D-character mascot account built on consistency,
strong character identity, loopable reels, and trending audio.

## The one-line strategy

> One lovable character. One reel a day. Same time, same energy, same face — so people
> start to *recognize* and *miss* him. Reach comes from dance + comedy; loyalty comes
> from quotes, advice, and kindness.

## Quick start (this week)

1. Lock the handle + bio → `strategy/account-strategy.md`
2. Batch-produce 7 reels (one per pillar) → `production/production-playbook.md`
3. Schedule them Mon–Sun at a fixed time → `content/weekly-schedule.md`
4. Repeat the weekly skeleton, swap the content. Consistency is the whole game.
