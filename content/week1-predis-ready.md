## How to load this into Predis (fast)
1. Brand Kit set (colors/voice/logo) — see `production/predis-workflow.md`.
2. For each day: new post → paste caption + hashtags → drop the visual (🎬 from Viggle / 🖼️ FLY still) → apply brand style → set the on-screen text beats.
3. Schedule all 7 at 6:00 PM ET, Mon–Sun. Turn on auto-post.
4. Only 3 days need outside motion (Mon/Tue/Sat); the other 4 are still + text inside Predis.
