# Predis.ai Workflow — FLY's Content Engine

You have **Predis.ai (paid)**. It becomes the **hub**: brand styling, weekly content
strategy, captions, hashtags, the reel editor, and **auto-scheduling** to Instagram +
TikTok — all in one place. It replaces Buffer and most of CapCut.

**The one job Predis does NOT do well:** animate a custom 3D character (FLY dancing) from
scratch. So we feed it FLY clips made elsewhere.

## Division of labor
| Job | Tool |
|-----|------|
| Animate FLY dancing / doing the action | **Viggle** (free) → also Kling/Dreamina |
| FLY stills in new poses | **Leonardo / Ideogram** (free) or your existing image |
| Brand styling, captions, hashtags, strategy, **editing + scheduling** | **Predis.ai** (paid) ✅ |

> Flow: make FLY's visual (Viggle/still) → **upload into Predis media library** → Predis
> styles it, writes the caption/hashtags, and auto-posts on schedule.

---

## STEP A — Set up Predis once (Brand Kit)

In Predis → **Brand Kit / Brand Settings**, enter:

- **Brand name:** Mini FLY Duck
- **Handle:** @miniflyduck (or your final pick)
- **Logo:** upload the `FLY ✌️` mark + the duck face
- **Colors (hex from the character bible):**
  - `#FFC21A` duck yellow · `#F47A20` orange · `#1A1A1A` ink black
  - `#36C9C0` teal · `#FF5C8A` pink · `#F6F2EA` off-white
- **Fonts:** one bold rounded display font (headlines) + a clean sans (body)
- **Tone of voice:** *Peaceful big-bro. Few words, real wisdom, funny when it fits.
  Effortlessly fresh. Always kind. Ends with "Stay fly. ✌️"*

Set this once and Predis keeps every post on-brand automatically.

---

## STEP B — Generate the week (Agent Mode)

Use Predis **Agent Mode** to build a strategically-linked week. Feed it this prompt:

```
Brand: Mini FLY Duck — a cute 3D streetwear duck mascot from Miami. Peaceful big-bro
energy, few words with real wisdom, funny when it fits, effortlessly fresh trendsetter.
Audience: 16–30, into sneakers, good vibes, feel-good and dance reels.

Build one week of vertical (9:16) short-form content, one post per day, on this fixed
schedule. For each day give me: a hook, an on-screen text overlay, a caption, and 6–8
hashtags. Keep captions short and warm, end with "Stay fly. ✌️".

- Mon — Move Monday: a dance moment + a short uplifting line
- Tue — Trick Tuesday: FLY tries an extreme sport (skate/surf/BMX), brave + fun
- Wed — Wisdom Wednesday: one inspirational quote with a real message (built to be saved)
- Thu — Real-Talk Thursday: gentle big-bro advice or a small act of kindness
- Fri — Funny Friday: a clean joke or pun (turn the humor up)
- Sat — Adventure Saturday: Miami lifestyle / come-with-me / sneakers / food
- Sun — Sunday Reset: gratitude / recharge / set the week up soft
```

Predis returns the week's hooks + captions + hashtags. You then drop FLY's visual into each.

---

## STEP C — Put FLY into each post
- **Dance/sport days:** make the clip in **Viggle** (free) → upload to the Predis media
  library → place it in the day's reel → Predis applies brand styling + text + audio.
- **Quote/advice/reset days:** Predis can build these almost entirely itself — use a FLY
  still from your library + Predis's text/templates. Minimal outside work.
- Use the Predis **scene-by-scene editor** to swap footage, fix timing, sync music, and
  drop the `FLY ✌️` watermark.

## STEP D — Schedule + auto-post
- In Predis, connect **Instagram + TikTok**.
- Schedule all 7 at the fixed daily slot (recommend **6:00 PM ET**).
- Turn on **auto-post**. Done — the week runs itself.

---

## The repeatable weekly rhythm (~60–90 min/week total)
1. Predis Agent Mode → generate next week's 7 posts (5 min).
2. Viggle → make the 2–3 motion clips you need (dance + sport) (20–30 min).
3. Drop clips into Predis, quick style pass on all 7 (20–30 min).
4. Schedule + auto-post the week (5 min).
5. During the week: only reply to comments as FLY.
